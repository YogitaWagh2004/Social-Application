**Social Media Web Application**

Tech Stack: Django, Python, HTML, CSS, JavaScript, PostgreSQL/MySQL

Developed a full-featured social media platform with the following key functionalities:

User Authentication & Profile Management: Implemented secure sign-in, sign-up, and logout functionality. Users can manage and update their profiles easily.

Post Creation & Engagement: Allowed users to create posts, upload images, and interact with posts through like/unlike features. Dynamic post feeds were implemented to enhance the user experience.

Follow/Unfollow Feature: Enabled users to follow and unfollow other users, enhancing social engagement within the platform.

Search & User Suggestions: Implemented robust search functionality for posts and users, along with an algorithm to suggest users to follow based on interests.

Account Settings & Security: Integrated an account settings page for users to update personal information, manage privacy settings, and ensure secure authentication.

Optimized Performance: Used efficient database queries and caching strategies to improve the app’s performance, ensuring fast response times even with large user data.

Responsive UI/UX: Designed a user-friendly interface using Bootstrap and Tailwind CSS, ensuring a seamless experience across both desktop and mobile devices.

Deployment & Scalability: Deployed the application on AWS/Render, ensuring high scalability and reliability for users worldwide.
